# NIST NVD MCP-сервер

Сервер предоставляет `search_vulnerabilities(project_name, limit=5)` через Streamable HTTP
по адресу `http://127.0.0.1:8001/mcp`. `limit` — целое число от 5 до 10.

Установите зависимости в окружение сервера и заполните `NIST_API_TOKEN` в `.env`
по образцу `.env.example`. Существующий `.env` перезаписывать не требуется.
Ключ NIST используется только сервером. Для доступа агента используется отдельный
`MCP_ACCESS_TOKEN`, необязательный при локальном запуске.

Из корня репозитория (в Windows можно использовать уже созданное окружение сервера):

```powershell
.\VulnSearchMCPServerExample\venv\Scripts\python.exe -m pip install -r VulnSearchMCPServerExample/requirements.txt
.\VulnSearchMCPServerExample\venv\Scripts\python.exe -m VulnSearchMCPServerExample.server
```

После активации нужного окружения поддерживаются оба способа запуска:

```powershell
# Из корня репозитория
python -m VulnSearchMCPServerExample.server

# Из каталога VulnSearchMCPServerExample
python server.py
```

Сервер можно перенести в отдельный репозиторий целиком. HTTP-транспорт и
авторизация находятся в локальном `http_server.py`; зависимости перечислены
в `requirements.txt`. Файлы проекта агента для запуска не требуются.

В настройках агента зарегистрируйте сервер с ID `nist` и URL
`http://127.0.0.1:8001/mcp`. Если задан `MCP_ACCESS_TOKEN`, в конфигурации агента укажите
имя переменной окружения, содержащей этот же секрет. NIST API-ключ агенту не нужен.

Пример вызова: `{"project_name": "Visual Studio Code", "limit": 5}`.
Возвращаются `status` (`ok` или `no_results`), `query`, `returned_count`, `limit`,
`limit_reached`, `search_note` и `vulnerabilities`. Каждая запись содержит `id`,
`description`, `url`, `published`, `last_modified`, `status` и `cvss`
(`version`, `score`, `severity`). Отсутствующие метрики обозначаются `null`.
Используется наиболее новая доступная версия CVSS; внутри версии предпочтительна
метрика с `type=Primary`.

Поиск идёт по ключевым словам в описаниях NVD, а не по точному CPE и версии.
Для `microsoft/vscode` полезнее название продукта `Visual Studio Code`, а не имя
репозитория `vscode`. Возможны совпадения для сторонних расширений и похожих продуктов.
Это первые записи NVD API, а не подборка самых новых или наиболее опасных CVE.
Если найдено меньше `limit`, сервер вернёт столько, сколько доступно.
`limit_reached=true` означает достижение лимита, но не подтверждает наличие следующей страницы.
`no_results` не доказывает отсутствие уязвимостей. Сетевые ошибки, неверный JSON,
ошибки ключа/квоты и timeout возвращаются как ошибки MCP-инструмента.

Используется `nvdlib==0.9.0`, синхронный запрос выполняется в отдельном потоке.
Один поиск загружает только одну страницу, без автоматических повторов. Внутренний
HTTP timeout библиотеки — 30 секунд на операцию сокета, ожидание MCP-инструмента
ограничено 40 секундами. Отмена ожидания не останавливает поток: новый поиск отклоняется
как занятый, пока старый реально не завершится. Поиск проектов выполняйте последовательно.
Между запросами выдерживается минимум 0,7 секунды; квота API-ключа общая и может
расходоваться другими приложениями. Библиотечная ошибка декодирования JSON, которую
`nvdlib` записывает в лог вместо исключения, также преобразуется в ошибку инструмента.

Документация: [NVD API](https://nvd.nist.gov/developers/vulnerabilities),
[ограничения NVD](https://nvd.nist.gov/developers/start-here),
[nvdlib: поиск CVE](https://nvdlib.com/en/latest/v2/CVEv2.html).
